# Batch 2 — Kube Implementation Plan

> **For agentic workers:** steps use `- [ ]`. Execution method: **native** (one agent,
> this session), same rhythm as the pods and healthcheck batches.

**Goal:** Export a pod as kube YAML and play/down YAML files from `gui.kubeDir`, behind
two lazy capabilities with syntax fallbacks and no hard-coded Podman versions.

**Spec:** `docs/superpowers/specs/2026-11-18-kube-design.md`

## Global Constraints

- No UI-goroutine podman/blocking file work; tasks use `exec.CommandContext`.
- New strings only in `pkg/i18n/english.go`.
- No `--replace`, no `--build`; play/down always confirmed with the full path.
- Files written `0600`, directory `0755`, overwrite only after confirmation.
- Never claim real-Podman verification: synthetic tests until the human checklist runs.
- End each task green: `gofmt -s -l main.go pkg/ scripts/`, `go vet ./pkg/...`,
  `go test ./...`, `golangci-lint run ./pkg/...`, `GOFLAGS=-mod=vendor` everywhere.

## Review Focus

1. Pod name `../../etc/x` must never write outside `gui.kubeDir` (`SafeKubeFilename`).
2. Cancel during `podman kube play` must kill the child and return promptly; no orphan
   `podman` process, no blocked UI.
3. A YAML file that disappears between listing and confirmation must fail with a clear
   message, not a panic.
4. Failed generate (stderr) must never show as a "saved" success.
5. `gui.kubeDir` missing for play/down is a message, not a crash; generate still creates it.

### Task 1: commands — probes, generate, streaming, file helpers

**Files:** create `pkg/commands/kube.go`, `pkg/commands/kube_files.go`,
`pkg/commands/kube_test.go`, `pkg/commands/kube_files_test.go`; modify
`pkg/commands/podman_client.go`, `pkg/commands/podman_cli.go`,

`pkg/commands/pod_test.go`, `pkg/gui/keys_test.go`, `pkg/gui/health_tab_test.go`.

**Interfaces (add to `PodmanClient`):**
- `ProbeSubcommand(ctx, variants [][]string) (argv []string, cap Capability)`
- `KubeGenerate(ctx, prefix []string, ref string) (string, error)`
- `StreamKube(ctx, prefix, args []string, onLine func(string)) error`
- `PodmanCommand.KubeGenerateCapability(ctx) (Capability, []string)`
- `PodmanCommand.KubePlayCapability(ctx) (Capability, []string)`
- `ScanKubeDir(dir string) ([]KubeFile, error)`, `type KubeFile struct{Name, Path string}`
- `SafeKubeFilename(name string) string`, `WriteKubeFile(path string, data []byte, overwrite bool) error`

- [ ] **Step 1: tests first**
  - `ProbeSubcommand`: dispatch script where `kube …` fails but `generate kube` succeeds →
    argv `["generate","kube"]`, available; both fail → unavailable, permanent; sleep script
    with a 50 ms budget → `Transient`.
  - `KubeGenerate`: script echoes YAML → returned verbatim; stderr + exit 2 → error contains
    the stderr text.
  - `StreamKube`: prints three lines → `onLine` sees them in order; sleeping script with a
    cancelled context → returns within ~1 s, `ctx` error.
  - `ScanKubeDir`: yaml+yml listed, subdirectory ignored, no-`kind:` file ignored, comments
    before `kind:` accepted, sorted by name, missing dir → error.
  - `SafeKubeFilename`: `../x`, `a/b`, `a b`, `..` → safe single-segment names.
  - `WriteKubeFile`: creates parent dirs, mode `0600`, refuses overwrite without the flag.
  - Capability: first success caches the prefix; a second call does not probe again.

- [ ] **Step 2: implement**, then `GOFLAGS=-mod=vendor go test ./pkg/commands/ -run 'Kube|ProbeSubcommand|ScanKube|SafeKube|WriteKube'`.
- [ ] **Step 3: extend fakes** in the three fake clients (return zero values) and build all.
- [ ] **Step 4: commit** `feat(kube): probe, generate and stream kube commands`.

## Manual checklist (human, rootless Podman)

1. Create pod + container, `g` → generate → preview has `kind: Pod` → save → `ls -l` shows
   mode `-rw-------`.
2. Pod with env vars → the confirmation contains the plaintext warning.
3. Generate the same pod again → overwrite prompt; Cancel keeps the old file (mtime same).
4. Play the saved file → output streams into the main panel, the pod appears in Pods.
5. Down it → confirmation shows the full path; Cancel spawns nothing.
6. `.yaml` without `kind:` and files in subdirectories are not listed.
7. On an old Podman, generate/play falls back to `podman generate kube` / `podman play kube`
   (or reports off) — record which.
8. `pgrep -a podman` before/after generate → one process, none left after.
9. Socket-only setup → both kube features report off lines, nothing spawned.
