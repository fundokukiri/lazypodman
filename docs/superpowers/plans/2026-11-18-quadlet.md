# Phase 4 — Quadlet export and auto-update: implementation plan

> **For agentic workers:** steps use `- [ ]`. Execution method: **native** (one agent,
> this session), same rhythm as the previous batches.

**Goal:** Export a container as a Quadlet `.container` unit and run
`podman auto-update` from the bulk menu, both with confirmation, preview/stream and
no background side effects.

**Spec:** `docs/superpowers/specs/2026-11-18-quadlet-design.md`

**Status:** both tasks done and committed (`3552f13`). Manual checklist lives in
`TEST.md` sections G–H.

## Global constraints

- Container inspect data only for the Quadlet file: no `systemctl`, no
  `podman generate systemd`.
- File `0600`, directory `0755`, single-segment name, overwrite only after a
  confirmation naming the full path.
- New strings only in `pkg/i18n/english.go`.
- `podman auto-update` runs in a task, streams verbatim, and is always confirmed.
- No new dependency; no hard-coded Podman behaviour beyond the documented mapping.
- Every task ends green: `gofmt -s -l main.go pkg/ scripts/`,
  `GOFLAGS=-mod=vendor go vet ./pkg/...`, `go test ./...`,
  `golangci-lint run ./pkg/...`, cheatsheet `check`.

## Review Focus

1. A container name like `../../etc/passwd` can never write outside `gui.quadletDir`
   (reuse `SafeKubeFilename`, assert the path's directory in a test).
2. `Q` on a container whose details are not loaded must refresh first, not emit an
   empty unit or panic.
3. The confirmation must always contain the full path and the plaintext warning, and
   Cancel must leave an existing file untouched.
4. Auto-update must not use the selection or the multi-select marks; its scope is the
   label, and the confirmation says what will run.
5. Cancelling the auto-update task kills the child; no orphan `podman` and no
   "finished" refresh that hides the cancellation.

### Task 1: commands — unit builder and shared writer

**Files:** create `pkg/commands/quadlet.go`, `pkg/commands/quadlet_test.go`; rename
`WriteKubeFile` → `WriteManifestFile` in `pkg/commands/kube_files.go` and its tests;
modify `pkg/gui/kube_menu.go` call site.

**Interfaces:**
- `BuildQuadletContainer(ctr *Container) string` — empty when inspect data is
  missing, never a partial unit.
- `WriteManifestFile(path string, data []byte, overwrite bool) error` — shared by
  kube and Quadlet, `0600` file, `0755` directory, refuses overwrite unless allowed.

- [x] Emit `Image=`, `ContainerName=`, sorted `Environment=`, `Exec=`, sorted
      `PublishPort=`, `Volume=`, `Network=`, then `[Service]`/`[Install]`.
- [x] Ports via `nat.PortMap` (the vendored Docker-compatible type used by inspect).
- [x] Tests: full mapping, nil/empty inspect → empty string, env sorting, port
      sorting.

**Done when:** kube tests still pass after the rename and the builder has no
filesystem access.

### Task 2: GUI — `Q` export and auto-update entry

**Files:** create `pkg/gui/quadlet.go`, `pkg/gui/quadlet_test.go`,
`pkg/gui/auto_update.go`; modify `pkg/gui/containers_panel.go`,
`pkg/gui/keybindings.go`, `pkg/gui/palette.go`, `pkg/config/app_config.go`
(`gui.quadletDir`), `pkg/i18n/english.go`.

**Interfaces:**
- `quadletDir() string` — config value, `~` expansion, default
  `<user config dir>/containers/systemd`.
- `quadletFilePath(name string) string`, `quadletSavePrompt(path, exists) string`.
- `handleContainerQuadletExport`, `promptQuadletSave`, `handleAutoUpdate`.

- [x] Refresh details when missing, build the unit, preview it in the main panel.
- [x] Confirmation with full path + overwrite state + plaintext warning; write with
      `WriteManifestFile`, flash `Saved <path>`.
- [x] `Q` binding on Containers; palette gains the auto-update entry.
- [x] Bulk menu gains **Auto-update containers**; confirm → stream in a task →
      refresh containers and services.
- [x] Config key `gui.quadletDir` without `omitempty` so `-c` shows it.
- [x] Tests: default/`~`/absolute directory, safe file name, prompt contents
      (full path, plaintext, "File exists"), `Q` bound once.

**Done when:** `-c` prints `quadletDir: ""`, builds pass on linux/windows/darwin,
and no test needs Podman.
