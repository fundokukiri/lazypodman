# Pods as first-class citizens — Implementation Plan (Phase 1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give lazypodman a Pods panel (list, tabs, actions) plus pod membership in the Containers panel, backed by a CLI-based `PodmanClient` next to the existing socket backend.

**Architecture:** A `PodmanClient` interface with one CLI implementation (`podman ... --format json`, `exec.CommandContext`, kill-on-close). One batched, single-flight refresh cycle per GUI refresh (`pod ls` + `ps`), cached in a `PodState` and joined to socket containers by full container ID with skew tolerated. GUI: `SideListPanel[*commands.Pod]` with Logs/Stats/Containers/Config tabs; panel focus keys get one source of truth so renumbering stays consistent.

**Tech Stack:** Go 1.22 (CI 1.24), `os/exec`, `encoding/json`, `jesseduffield/gocui`, existing `panels.SideListPanel`, `tasks.TaskManager`, `stretchr/testify`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-18-pods-design.md`

**Builder deviations from the spec (decided, not open):**
- Pod stats are computed by summing the **existing socket stats** of the pod's member containers. `podman pod stats --format json` is not used in v1: its JSON shape cannot be verified in this environment, and one source of truth avoids contradicting numbers.
- Pod logs prefer `podman pod logs --follow --names -- <pod>` when the CLI advertises `--names` (Podman ≥ 4.1); otherwise one `podman logs --follow --names` process per container. The per-container path needs no prefix parsing at all.
- The disabled reason is shown in the existing bottom-right information view as `pods off: <reason>` (short codes only, full detail in the debug log) — no popup, no transient status.

**Approval conditions folded in:**
- Every fixture under `pkg/commands/testdata/pods/` is **synthetic and unverified**; parsers must be re-tested against real captures from a Podman machine (checklist step 15).
- Pod ports come from the **infra container** (captured before infra containers are filtered out of the container list), not from member containers; `--infra=false` ⇒ no ports.
- Enablement budget is **5 s**, and `gui.pods.enabled` (`auto|always|never`) is the escape hatch for cold rootless starts.
- `fd://` and `ssh://`/`tcp://` sockets are **not comparable** paths; `EvalSymlinks` failure falls back to the cleaned path.
- Container map uses `podman ps -a`; `--external` is **not** passed (containers from outside Podman are not ours to manage).

## Global Constraints

- `GOFLAGS=-mod=vendor` for every Go command; **no new dependencies**; `vendor/` must stay byte-identical after `go mod vendor`.
- Minimum supported Podman: **3.0.0** (CLI wrapper); `--names` for pod logs requires **4.1**, detected at runtime, not assumed.
- New user-visible strings only in `pkg/i18n/english.go`; other languages fall back to English.
- Never shell-interpolate pod/container names: argv only, `--` before positional args, reject refs starting with `-`.
- Long-running work (logs streaming, stats polling) runs inside `tasks.TaskFunc`; the UI goroutine never blocks.
- Destructive actions (remove, force remove, prune) go through the existing confirmation panel.
- Never log secret/env values; log names and IDs only.
- Local test runs: `go test ./...` (no gcc in this environment, so no `-race` locally). CI runs `-race`.
- Conventional Commits; each task ends with one commit.

## Review Focus

1. **Pod/container names that need escaping** — `web api`, `it's`, `a"b`, or a name starting with `-`. Expected: the command still targets exactly that pod and a leading-dash name is rejected with a readable error, never passed as a flag.
2. **Log lines that look like prefixes** — a line starting with another container's name (`webbish: x`), containing `:`/spaces, or empty. Expected: correct attribution or plain fallback, no dropped or duplicated text.
3. **Socket/CLI snapshot skew** — container in the socket list that the CLI map lacks, map entry with no container, pod removed between refresh and action, pod created with `--infra=false` (`InfraId == ""`). Expected: empty pod cell, no panic, no wrong pod shown.
4. **Socket path forms** — `unix://` prefix, trailing slash, `/var/run` symlink to `/run`, relative CLI path, empty CLI path. Expected: healthy machines stay enabled; only genuine mismatches disable Pods.
5. **Missing, slow or hanging `podman` CLI** — binary absent, version output in an unexpected format, `info` hanging. Expected: startup bounded (~3 s), Pods hidden with a reason, all socket features still work; leaving the Logs tab kills child processes.

	in         string
	want       string
	comparable bool
}

func TestNormalizeSocketPath(t *testing.T) {
	cases := []normalizeCase{
		{"/run/user/1000/podman/podman.sock", "/run/user/1000/podman/podman.sock", true},
		{"unix:///run/user/1000/podman/podman.sock", "/run/user/1000/podman/podman.sock", true},
		{"unix:///run/user/1000/podman/podman.sock/", "/run/user/1000/podman/podman.sock", true},
		{"unix:////run/user/1000/podman/podman.sock", "/run/user/1000/podman/podman.sock", true},
		{"/run/user/1000/podman/./podman.sock", "/run/user/1000/podman/podman.sock", true},
		// nonexistent path: EvalSymlinks fails, the cleaned path is used
		{"/does/not/exist/../podman.sock", "/does/not/podman.sock", true},

		{"ssh://core@host/run/user/1000/podman/podman.sock", "", false},
		{"tcp://10.0.0.1:2375", "", false},
	}
	for _, c := range cases {
		got, comparable := normalizeSocketPath(c.in)
		if got != c.want || comparable != c.comparable {
			t.Errorf("normalizeSocketPath(%q) = (%q, %v), want (%q, %v)", c.in, got, comparable, c.want, c.comparable)
		}
	}
}

func TestNormalizeSocketPathResolvesSymlinks(t *testing.T) {
	dir := t.TempDir()
	target := filepath.Join(dir, "podman.sock")
	link := filepath.Join(dir, "link.sock")
	require.NoError(t, os.WriteFile(target, nil, 0o600))
	require.NoError(t, os.Symlink(target, link))
	assert.Equal(t, normalizeSocketPath(target), normalizeSocketPath("unix://"+link))
}

func TestNormalizeSocketPathWindows(t *testing.T) {

		t.Skip("windows only")
	}
	got, comparable := normalizeSocketPath("npipe:////./pipe/podman")
	want, _ := normalizeSocketPath(`\\.\pipe\podman`)
	assert.True(t, comparable)
	assert.Equal(t, want, got)
}
